# 佛門梵唄 — 板眼資料

《佛門必備課誦本》的板眼（法器點板）資料，供「佛門梵唄」App 讀取。
純靜態檔，沒有 API：一個 `catalogue.json` 目錄，加上各篇一個 `.banyan`。

## 來源

- 底本：《佛門必備課誦本》淨律寺重排版（CH610-37）
- 板眼、文字由掃描本經版面分析與 OCR 抽出，再以權威本校字
- 少數篇章（如〈爐香讚〉）為人工校對版

## 格式

`.banyan` 是人看得懂的 JSON。一篇是一個 `Score`，底下 `lines`（行，由右至左）
各含 `chars`（字），每個字帶：

| 欄位 | 意思 |
|---|---|
| `text` | 本字；空字串＝純符號格（過門、收板、休息鼓） |
| `marks` | 板眼符號，圈／劃／磬類等 |
| `note` | 註記小字與第二層符號（三拜、轉板、收板⋯） |
| `pulse` | 唱的人數的拍。沒寫＝由板眼推算（板眼幾拍就幾拍，0 拍算一拍） |

`catalogue.json` 每篇多一個 `rev`（內容雜湊），App 靠它判斷哪幾篇更新了。
